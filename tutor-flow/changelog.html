Changelog

Tutor Flow is maintained alongside Ringle's own updates. When something on Ringle's side changes and Tutor Flow needs to catch up, it'll show up here.

1.0.3 9 October 2026
  • Free plan — Tutor Flow now works without a license. Free covers the formatting shortcuts and Calendar Defender on your first calendar; Premium adds the Student Tracker, the feedback tools, extra calendars, holiday overlays, manual blocks and recurring-offer conflict checks. First-time subscribers can try Premium free for 10 days from the popup.
  • Paraphrases keep their formatting — Ctrl/⌘+1, typed arrows and the Paraphrase button now carry the sentence’s bold and highlights into Ringle’s copy and clear them from the original. Correction formatting (orange, strikethrough) stays where it was.
  • Paraphrase fixes — words with a format change in the middle no longer split apart (“wing s”), a Ctrl/⌘+2 correction no longer leaves double spaces in the copy, and a new paraphrase can no longer overwrite the text of an older one. The fixes also run on the live Docs page now, which they weren’t before.
  • Format shortcuts mid-drag — pressing Bold or a highlight shortcut while you’re still dragging a selection word by word now formats the whole selection, not part of it.
  • Shift no longer scrolls — holding Shift while extending a long selection used to jump the doc back to where the selection started. It stays put.
  • Pasted questions — after pasting copied questions, the caret lands under the first question, ready for the answer.
  • Feedback page — it now opens on Ringle’s default view, with Docs still one click away. The import step opens Docs for you if Ringle hasn’t.
  • Question selector — fixed selected questions not being picked up after Ringle changed the colour of its selected-question badge.
  • Student Tracker — the monospace font is gone, and there’s a new 📱 flag for phone and tablet students. It shows in the pill and opens that student’s lesson notes in a background tab once per lesson.
  • Docs help box — a new Tutor Flow tab lists the shortcuts, and the help icon glows until you click it for the first time.
  • Review prompt — the popup now asks for a Chrome Web Store review after you’ve had Tutor Flow installed for two weeks. You can snooze it.
1.0.2 2 October 2026
  • Listing updates — the Chrome Web Store listing has been refreshed. No changes to features.
1.0.0 Initial release
  • Feedback Exporter — bold a phrase in the lesson doc and it's pulled out as its own key expression on the Feedback Report, split apart automatically.
  • Formatting Shortcuts — asterisks for bold, brackets and hyphens for corrections, self-pairing quotation marks, a highlight toggle, and active-line centering, all without reaching for a toolbar.
  • Calendar Defender — connect Google Calendar to see your existing commitments directly on Ringle's booking grid, with separate Regular and Holiday overlays and recurring-offer conflict checks.
  • Student Tracker — searchable roster with per-student notes that persist across lessons.

That's everything so far — this page will grow as new versions ship.
